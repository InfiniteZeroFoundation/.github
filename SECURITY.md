# Security Policy

## Scope

This policy covers all InfiniteZero Foundation repositories, including the DIN smart contracts and the `dincli` tooling in [DevNet](https://github.com/InfiniteZeroFoundation/DevNet).

DIN is currently running as **DevNet 2.0** on the Optimism Sepolia test network. No real-money value is at stake yet, but we treat every vulnerability seriously because the same code is headed for testnet and mainnet.

## Reporting a vulnerability

**Please don't open a public GitHub issue for security problems.**

Instead, email **abrahamnash@protonmail.com** with "SECURITY" in the subject line, and include:

- what you found and where (contract, file or command);
- steps to reproduce, or a proof of concept;
- the impact you think it has.

We aim to acknowledge reports within **3 working days** and to keep you updated until the issue is resolved. With your permission, we'll credit you when the fix is published.

## Known issues

Security findings we already know about are tracked openly in the DevNet issues, along with our [adversarial threat model](https://github.com/InfiniteZeroFoundation/DevNet/blob/develop/Developer/design/adversarial-threat-model.md). Please check there first.

## Bug bounty

There is no paid bug bounty yet. We plan to revisit this before mainnet.
